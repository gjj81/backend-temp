# 页面结构与路由规范（views 层）

> 约定基线：Vue3 + Vite + Pinia + Vue Router + Element Plus（或同类组件库）。
> 组件命名 PascalCase，目录小写，路由 path 全小写、按模块分层。

---

## 一、views 目录结构

```
src/views/
├── sales/                          # 销售管理
│   └── plan/                       # 销售计划（现有页面归属这里）
│       ├── PlanEntry.vue           # 计划录入 —— 对应现在「计划录入」页（左侧表单+右侧明细）
│       ├── PlanList.vue            # 计划列表（查询/确认/下发/退回/归档）  ...
│       └── PlanCalendar.vue        # 计划日历（按月看计划分布）
│   └── ...

├── schedule/                       # 生产排程
│   ├── ScheduleBoard.vue           # ★ 排产工作台（甘特+池子+编辑条，唯一需要三层的页面）
│   └── components/                 # 仅工作台内部复用的子组件，不对外
│       ├── PoolPanel.vue           # 左侧待排产池
│       ├── GanttChart.vue          # 产线泳道甘特（拖选/拖块/分行渲染）
│       ├── SpanBlock.vue           # 单个排产块（四种状态样式）
│       └── EditBar.vue             # 顶部编辑条（改每天数量/天数）
│
├── shop/                           # 车间
│   └── ShopKanban.vue              # 车间看板（待开工/生产中两列卡片）
│
└── base/                           # 基础资料
    ├── Workshop.vue                # 车间维护
    ├── ProdLine.vue                # 产线维护（挂车间下）
    └── Product.vue                 # 产品维护
```

### 命名规则

| 项 | 规则 | 示例 |
|---|---|---|
| 模块目录 | 小写单数，按业务域分 | `sales/`、`schedule/`、`shop/` |
| 页面组件 | PascalCase + 业务后缀 | `PlanEntry.vue`、`ScheduleBoard.vue` |
| 页面专属子组件 | 页面目录下 `components/` 子目录 | `schedule/components/GanttChart.vue` |
| 跨页面复用组件 | 放 `src/components/`，不进 views | `src/components/StatusBadge.vue` |
| 路由 name | 与组件名一致 | `name: 'ScheduleBoard'` |
| 路由 path | 小写，模块/页面两级 | `/schedule/board` |



## 三、每个页面要不要三层（结论表）

三层 = 组件层 + store 转发层 + api 层；两层 = 组件层 + api 层（组件内 ref 管理状态，直接调 api）。

| 页面 | 复杂度 | 架构 | 理由 |
|---|---|---|---|
| ScheduleBoard 排产工作台 | 高 | **三层** | 甘特/池子/编辑条共享一份状态；行状态回写、守卫 G3/G7/G8、批量下发要收敛到 store，避免各组件重复实现 |
| ShopKanban 车间看板 | 低 | **两层** | 只读列表 + 开工/完工/撤销三个动作，无跨组件共享状态；以后要做轮询刷新再接入 store |

### store 只建一个，按模块切

```
src/stores/
└── schedule.js        # 只有排产工作台需要：state / actions（含回写与守卫）/ getters
```

其他页面的接口直接走 `src/api/*.js`：

```
src/api/
...
```

## 四、排产工作台的组件边界（对照原型）

| 原型功能 | Vue 归属 |
|---|---|
| 待排产池卡片、按最早交货排序、未排满警告 | `PoolPanel.vue`（排序用 computed getter） |
| 甘特表头、产线泳道、今日/交货节点标记 | `GanttChart.vue` |
| 拖选跨天、拖块换线、区间分行防重叠 | `GanttChart.vue` 内部纯 UI 计算，产出 `span` 对象 emit 给 store |
| 排产块四态样式（草稿/已确认/生产中/完工） | `SpanBlock.vue` |
| 点块改每天数量/天数/开始日期 | `EditBar.vue`，保存走 `store.updateSpan()` |
| 批量下发、行状态回写、守卫拦截 | `stores/schedule.js` |
| 车间看板两列卡片 | `ShopKanban.vue` 内部子区块，不值得再拆文件 |

## 五、页面详细设计

### 5.1 PlanEntry.vue 计划录入 【已确认，按现有页面】

```javascript
┌──────────────────────────────────────────────────────────────────────┐
│ 面包屑：首页 / 销售管理 / 销售计划                                      │
│ 页签： [计划录入] [计划日历]                        [导出 excel]        │
│ 月份： [2026-05 ▾]                                                     │
├────────────────────┬─────────────────────────────────────────────────┤
│ 左：新增销售计划    │ 右：计划明细卡片（按客户分组）                     │
│  *客户  [______]   │  ┌ 奇瑞汽车  奇瑞汽车-2026-05  [待确认]  [＋][🗑] ┐ │
│  *计划名称[_____]  │  │ 零件      订单量  交货日期和数量  预测 库存 状态 删除│ │
│  *计划月份[_____]  │  │ 1.5T进气  5,000  +[05-18 3000][05-22 2000] 5000 3700 待生产 ✕│ │
│  产品明细          │  │ 1.5T排气  5,000  [05-13 2000][05-14 2000]…  5000 3300 生产中 🔒│ │
│  ┌ 产品 #1 ──────┐ │  └─────────────────────────────────────────────────┘ │
│  │ *产品名称[__] │ │  ┌ 科泰克  科泰克-2026-05  [已确认]  [＋][🗑] ┐      │
│  │ *订单总量[__] │ │  │ …                                                │ │
│  │  预测数量[__] │ │  └─────────────────────────────────────────────────┘ │
│  │  期初库存[__] │ │                                                  │
│  │ 交货计划       │ │                                                  │
│  │  ┌交货#1─────┐│ │                                                  │
│  │  │*交货日期  ││ │                                                  │
│  │  │*交货数量  ││ │                                                  │
│  │  └───────────┘│ │                                                  │
│  │  [＋添加交货]  │ │                                                  │
│  └────────────────┘ │                                                  │
│  [＋添加产品]        │                                                  │
└────────────────────┴─────────────────────────────────────────────────┘
```

- 左侧表单：客户、计划名称、计划月份必填；产品可多个（产品 #1、#2…），每个产品含订单总量（必填）、预测数量、期初库存、交货计划（交货 #1、#2…，日期+数量必填）。
- 右侧明细：按客户分组成卡片，组头显示客户名、计划编号、状态徽标（待确认/已确认/生产中）、追加(＋)与删除(🗑)。
- 行内：交货日期和数量以 chip 展示，可追加(+)；状态列（待生产/生产中）；删除仅在行未下发时可用（守卫：行=0）。
- 状态规则【已确认】：整单未下发才可编辑/删除；下发后锁定，仅可追加已有产品（新行=0 待单独下发）。

### 5.4 ScheduleBoard.vue 排产工作台 【已确认，按已定稿原型】

```javascript
┌──────────────────────────────────────────────────────────────────────┐
│ 工具栏：车间[机加车间▾]  2026-05  客户[全部▾]   待确认 3 条  [批量下发][重置]│
├──────────────────┬───────────────────────────────────────────────────┤
│ 待排产池(300px)   │ 选中行信息条：零件 状态 订单/已排/草稿  未排满⚠      │
│ 按最早交货排序    │ 交货节点参照条：05-08前4000 …（日期表头同步标红）     │
│ ┌──────────────┐ │ 编辑条：每天[__]件 ×[__]天 开始[__] [保存][删除]      │
│ │●1.5T进气      │ ├───────────────────────────────────────────────────┤
│ │ 待排程        │ │ 产线＼日期  01 02 … 06(今) … 18◆ 22◆ …              │
│ │ 订单5,000     │ │ 一号机  ░░░░░░ [====1500/天×5====]                   │
│ │ 已排0 剩5,000 │ │ 二号机  [==1000/天×3 生产中==]                       │
│ │ ▱▱▱▱▱ ⚠未排满 │ │ 三号机              [====1800/天×4====]             │
│ │ 05-18 3000🔴  │ │ （同一产线同一天可叠多个产品，自动分行）              │
│ └──────────────┘ │                                                   │
└──────────────────┴───────────────────────────────────────────────────┘
```

- **工具栏**：车间下拉（切换甘特和看板的车间范围）、月份、客户过滤、待确认条数徽标、批量下发、重置。
- **待排产池**（PoolPanel）：每行卡片 = 颜色点+零件名、状态徽标（待排程/已排程/生产中/已完成）、客户/预测/库存、订单/已排/剩余、进度条（未排满黄色）、交货节点 chips（7 天内红色）、⚠未排满。点击卡片选中（决定新排产属于谁），排序按最早交货日期。
- **信息条**：选中行的零件、状态、订单量、已排、草稿量、未排满差额。
- **交货节点参照条**：选中行的节点（日期前数量）；甘特表头对应日期标红下划线，悬停显示应交数量。
- **甘特**（GanttChart）：维度=车间，泳道=产线；表头 31 天，今日列红字+浅红底；排产块按 状态四态着色（草稿=白底蓝虚线 / 已确认=蓝底 / 生产中=橙底 / 已完工=灰底），左色条区分产品，块显示「每天数量×天数」；同一天同产线多个产品自动分行堆叠。
- **编辑条**（EditBar）：点草稿块出现——每天数量、天数、开始日期可改，保存/删除；非草稿只读信息。
- **交互**【已确认】：
- 产线空白处**单击** = 给选中行排 1 天（默认 1000/天，选中即改）；
- **按住左右拖** = 跨天排产（每天同量），**可上下拖到其他产线**；
- 拖虚线块 = 整块换日期/换产线；点块 = 编辑；
- 任何操作后甘特/池子滚动位置保持不动。
- **守卫**【已确认】：行未下发不进池子（G3）；排产总量 ≥ 订单量提示未排满（G7，允许超排）；有填报数据的排产禁止撤销（G8）；批量下发 = 草稿整段 0→1 已确认。
- **行状态回写**：有已确认排程→已排程；有生产中→生产中；全部完工→已完成；全部撤销→待排程。

### 5.5 ShopKanban.vue 车间看板 【已确认，按原型】

```javascript
┌ 待开工（排产=1 已确认）─────────┬ 生产中（排产=2）────────────────┐
│ ┌────────────────────────────┐ │ ┌────────────────────────────┐ │
│ │ 1.5T排气凸轮轴    3,000 件  │ │ │ 1.5T排气凸轮轴    3,000 件  │ │
│ │ 二号机·05-06起3天 奇瑞      │ │ │ 二号机·05-06起3天 奇瑞      │ │
│ │              [开工] [撤销] │ │ │              [完工]        │ │
│ └────────────────────────────┘ │ └────────────────────────────┘ │
```

- 卡片字段：零件名、产线+日期+天数、客户、总量；有填报数据显示标记。
- 操作：待开工卡 = 开工（→2）、撤销（→0，有数据时禁）；生产中卡 = 完工（→3 终态）。
- 按路由 query.ws 过滤车间，与工作台联动。

### 5.6 base/* 资料维护 【设计】

- Workshop：车间编号、名称；ProdLine：产线编号、名称、所属车间；Product：产品编号、名称、所属客户、启停。
